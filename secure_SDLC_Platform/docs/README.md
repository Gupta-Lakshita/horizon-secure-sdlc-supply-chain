# Horizon Relevance Client Documentation

Start with [00-client-documentation-index.md](00-client-documentation-index.md). It lists the recommended reading order for client platform admins, developers, QA engineers, release managers, security reviewers, and product stakeholders.

The most common client path is:

1. Onboarding and architecture.
2. IAM/EKS prerequisites.
3. License contract and license-management flow.
4. Client values preparation.
5. Installer lifecycle and runbook.
6. Build, validation, release promotion, and deployment runbook.
7. Client-hosted test plan.

For hands-on build and release usage, open [build-release-deployment-runbook.md](build-release-deployment-runbook.md) or download [build-release-deployment-runbook.docx](build-release-deployment-runbook.docx).

For Horizon-owned trial, paid, and enterprise subscription operations, open [license-management/phase-1-license-management-service.md](license-management/phase-1-license-management-service.md).
